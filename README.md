# Birthday Quiz #26

A 5-round birthday trivia quiz, playable in the browser.

## Play it

Once GitHub Pages is enabled for this repo (Settings → Pages → Source: Deploy from branch → `main` → `/ (root)`), the quiz will be live at:

`https://mityasereda.github.io/birthday-quiz-26/`

## Rounds

1. September 26th
2. Uroboros
3. Not only metal bands
4. Matrix — CHA·GAL
5. Not only psychoanalytic diagnosis

Navigate with the arrow keys, on-screen arrows, or by swiping. Click the "ROUND x OF 5" tag at any time to jump to a specific round.
